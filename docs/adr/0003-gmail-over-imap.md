# Gmail over IMAP in v1, not the Gmail API

In v1, Gmail is an IMAP provider like iCloud and generic servers, with its differences limited to capability flags and a few overrides (X-GM-THRID thread ids, X-GM-LABELS, X-GM-RAW search). Gmail likely lacks QRESYNC and possibly CONDSTORE, so detecting flag changes made on other devices means re-reading flags over the 90-day sync window on a timer, which is crude but cheap for one user. The Gmail API would give history-based sync and server-side scheduled send, but a second code path in v1 is the coupling that made Exo hard to extend. The Gmail API is planned as a separate provider after v1, behind the same provider interface.
