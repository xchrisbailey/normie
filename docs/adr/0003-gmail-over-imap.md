# Gmail over IMAP in v1, not the Gmail API

In v1, Gmail is an IMAP provider like iCloud and generic servers, with its differences limited to capability flags and a few overrides (X-GM-THRID thread ids, X-GM-LABELS, X-GM-RAW search). A live check on Nov 26, 2026 ([issue #2](https://github.com/xchrisbailey/normie/issues/2)) found Gmail offers CONDSTORE but not QRESYNC: flag changes come from CHANGEDSINCE, and deletions are found by comparing UID sets. The Gmail API would give history-based sync and server-side scheduled send, but a second code path in v1 is the coupling that made Exo hard to extend. The Gmail API is planned as a separate provider after v1, behind the same provider interface.
